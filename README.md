# Avaliação da taxa de crescimento do Tribolium castaneum Herbst durante o armazenamento de milho

Este repositório contém os dados e scripts utilizados na transformação do Trabalho de Conclusão de Curso (TCC) em artigo científico para submissão à revista **Journal of Stored Products Research**.

## 📌 Resumo do Projeto
O objetivo desta pesquisa é analisar a dinâmica populacional e a taxa de crescimento do *Tribolium castaneum* (Herbst) em diferentes condições de armazenamento de milho. O *T. castaneum* é uma das principais pragas secundárias de grãos armazenados, e entender sua taxa de crescimento é crucial para o desenvolvimento de estratégias de Manejo Integrado de Pragas (MIP).
